<h1>Maju Mundur Store Backend API</h1>
This project is a backend API for a fictional store, Maju Mundur. The API provides functionality for product management by merchants and product purchase transactions.
<h2>Key Features</h2>
<ul>
  <li><b>Product Management</b>: Merchants can add, view, and update products.</li>
  <li><b>Purchase Transactions</b>: Customers can purchase products. Automatically updates product stock upon successful purchase.</li>
  <li><b>Validation</b>: Enable validation such as ensuring stock availability before processing transactions.</li>
  <li><b>Relational Database Management</b>: Implements relational mapping using Hibernate.</li>
</ul>
<h2>Technologies Used</h2>
<ul>
  <li><b>Java Spring Boot</b>: For building the RESTful API.</li>
  <li><b>Hibernate</b>: For object-relational mapping and database interactions.</li>
  <li><b>PostgreSQL</b>: For data storage and management.</li>
</ul>
